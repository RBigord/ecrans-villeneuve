# Fichiers fournis pour les étapes 7 et 8

- `etape7/ApiVenteTest.java` teste l'API Spring Boot de l'étape 7.
- `etape8/VentePartenaireApiTest.java` teste la vente partenaire SortiesFlash de l'étape 8.

Ils sont rangés ici, **hors de `src/`**, parce qu'ils ne compilent pas tant que Spring n'est pas dans le `pom.xml`.
Une fois la section 7.1 du sujet faite, copiez chacun dans `src/test/java/com/ecrans/vente/etape7/` ou `.../etape8/`.
